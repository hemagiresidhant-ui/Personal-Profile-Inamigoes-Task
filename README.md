# Siddhant Hemagire - Personal Portfolio Website

## Overview

This is a responsive personal portfolio website developed to showcase my educational background, technical skills, projects, and contact information. The website is designed with a modern dark-themed user interface and provides a professional online presence.

## Features

* Responsive single-page portfolio design
* Modern dark theme with clean user interface
* Fixed navigation bar with smooth scrolling
* About Me and Education section
* Technical Skills section
* Project Portfolio section
* Contact Information section
* Mobile-friendly layout
* GitHub repository links for projects

## Technologies Used

* HTML5
* CSS3
* Responsive Web Design
* Flexbox
* CSS Grid

## Sections Included

### Home

* Professional introduction
* Career objective
* Quick navigation to projects

### About & Education

* Personal introduction

* Educational achievements

### Contact
